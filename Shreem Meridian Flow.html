    Narration

    Chakra and organ positions are placeholders until your own chakra model and colors are added. Brain regions follow standard anatomy; the Soulseat marks the location given in the script. This is a guided visualization of the practice.

    Linking this player from other parts

    Each scene has its own address. Add the scene name after # in this page's link. Add -brain to open it with only the brain, full size, and -solo to show only the animation, looping that one scene, for embedding inside another page. They combine, for example #fire-brain-solo.

    SceneLink endingStage only

    A page that embeds this player can control it and listen to it with messages:

    // send to the player
frame.contentWindow.postMessage({type:"shreem:goto", scene:"fire"}, "*");
frame.contentWindow.postMessage({type:"shreem:play"}, "*");   // or shreem:pause
frame.contentWindow.postMessage({type:"shreem:brain", on:true}, "*");
frame.contentWindow.postMessage({type:"shreem:model", model:{...}}, "*"); // your chakra model

// the player announces
// {type:"shreem:scene", id:"fire", num:6}
// {type:"shreem:step",  scene:"fire", index:3, label:"Both eyes", node:"eyes", region:null}
// {type:"shreem:ended", id:"fire"}

    Inside the same page the player is also available as window.ShreemFlow with goto(), play(), pause(), brain(), setModel() and getModel(). Scenes, paths, colors, organs, chakras and brain regions all come from the model data at the top of this file.
